# Dataset Evaluation

## Dataset 1: dataset.xlsx

### Pros

- Contains Transaction ID
- Contains Payment Status
- Contains Reason column
- Contains Service Type

### Cons

- Limited bank information
- Appears to cover multiple financial services, not only UPI

**Decision:** Selected as a supporting dataset.

---

## Dataset 2: Github dataset_1.xlsx

### Pros

- Rich transaction details
- Bank information
- Timestamp
- Payment Method
- Device Type
- Merchant
- Status

### Cons

- No explicit Failure Reason

**Decision:** Selected as the primary dataset.

---

## Dataset 3: Phonepe-Final-Dataset.xlsx

### Pros

- Similar to Dataset 1
- Includes Reason column

### Cons

- Limited additional value over Dataset 1

**Decision:** Backup dataset.
