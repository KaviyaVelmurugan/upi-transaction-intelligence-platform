# Final Dataset Selection

## Selected Datasets

### Primary Dataset

Github dataset_1.xlsx

Reason:
Provides the richest transaction-level information required for SQL analysis, Python EDA, Power BI dashboards, and machine learning.

### Supporting Dataset

dataset.xlsx

Reason:
Contains a Reason column that can be used for failure pattern analysis.

### Backup Dataset

Phonepe-Final-Dataset.xlsx

Reason:
Retained as an alternative reference dataset.

## Dataset Limitations

Public UPI transaction datasets with detailed production-level failure reasons are not publicly available due to privacy and security considerations. Therefore, this project uses publicly available datasets while documenting their limitations.
